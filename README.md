# Small Category

Small Category is a simple Flutter-based mobile catalog application developed for educational purposes.

## Features

- Product listing with GridView
- Product detail screen
- Product search and filtering
- Page navigation with Navigator
- JSON simulation with fromJson / toJson
- Product quantity selection
- Add to cart functionality
- Cart screen
- Remove products from cart
- Total price calculation
- Local asset image management

## Technologies

- Flutter
- Dart
- Material Design
- Android SDK
